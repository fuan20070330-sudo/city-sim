# 城智演 · 3 分钟演示脚本

> 目标：用一条完整故事讲清“事件注入 → 多智能体派车 → 断路 → 重规划 → 指标 → 复盘”。

## 0:00–0:15 开场

操作：停留在初始态势图。

讲解：

> 城智演是一个纯静态的城市应急多智能体调度推演平台。它不依赖地图 API、后端或 GPU，仿真与路径规划运行在 Web Worker 中，所有能力都可以直接在 GitHub Pages 上运行。

## 0:15–0:35 启动剧情

操作：点击顶部 **“剧情演示”**。

讲解：

> 内置场景同时注入了滨江物流园三级火灾和老城社区医疗急救。三级火灾不是派一辆车，而是自动编成两辆消防车加一辆物资车；医疗事件同时派出一辆救护车。

观察：地图上四类任务单元开始移动，左栏资源利用率上升，底部出现派车事件。

## 0:35–1:00 说明地图与指标

操作：指向地图路径、左栏四项指标。

讲解：

> 每个颜色对应一类智能体。路径通过 A* 搜索得到，代价综合了距离、限速、车道和交通系数。左栏实时展示平均响应、应急覆盖率、拥堵度和资源利用率。

## 1:00–1:25 断路与动态重规划

操作：等待标准剧情自动注入断路，指向底部出现 **“动态重规划”** 的事件。

讲解：

> 这里不是预录制动画。道路封闭后，图结构发生变化，引擎检测到活动路线经过封闭边，立即从车辆当前节点重新搜索。可以看到重规划事件、ETA 和新路线同步更新。

操作：可点击右栏 **“资源”**，展示车辆的“重规划次数”。

## 1:25–1:50 算法对比

操作：切到右栏 **“算法”**，点击 **“运行四组算法对比”**。

讲解：

> 四组对比分别是 A*/Dijkstra 与最近优先/负载均衡。A* 使用可采纳的欧氏距离下界，在保持时间最优的同时减少探索节点。最近优先追求最快到场，负载均衡则加入车辆历史出动惩罚，避免单台车辆过载。

## 1:50–2:10 路网编辑与事件注入

操作：选择地图左侧 **“路网”**，点击一条道路切换封控/恢复；说明点击两个路口可新建通道。

讲解：

> 城市不是固定画面。道路可以封控、恢复、删除或新增，资源可以部署到任意路口，也可以继续注入火灾、医疗或内涝事件。

## 2:10–2:25 场景持久化

操作：点击顶部 **“场景”**，展示本机场景库、保存与 JSON 导入导出。

讲解：

> 当前路网、资源编成和事件配置可以保存到本机，也可以导出 JSON 作为现场备份。整个过程没有服务器参与。

## 2:25–2:45 过程回放

操作：关闭弹窗，拖动底部时间轴到派车或断路节点。

讲解：

> 每次时间推进都会形成快照，拖动时间轴可以回到任意时刻，复看当时的事件、路线和指标，不需要重新推演。

## 2:45–3:00 收束

讲解：

> 城智演把路网编辑、事件注入、多智能体协同、动态重规划和可解释算法对比放在同一套确定性仿真中。它可以在普通浏览器离线运行，也适合部署为面向公众的静态演示平台。

## 现场兜底方案

- 如果现场网络不可用：直接运行本地 `pnpm preview`，所有核心功能仍可用。
- 如果自动剧情已运行结束：点击“重置场景”后再点击“剧情演示”。
- 如果评委想逐分钟观察：暂停自动播放，使用“单步推进”或时间轴。
- 如果误改路网：点击顶部重置，或重新载入内置示范场景。
